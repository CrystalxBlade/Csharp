| Hashtable                     | Dictionary<TKey, TValue>                      |
| ----------------------------- | --------------------------------------------- |
| Legacy collection             | Modern generic collection                     |
| Introduced in .NET 1.0        | Introduced in .NET 2.0                        |
| Stores `object`               | Stores specific types (`int`, `string`, etc.) |
| Not type-safe                 | Type-safe                                     |
| Requires casting              | No casting needed                             |
| Slower due to boxing/unboxing | Faster                                        |
| Rarely used in new code       | Used in almost every modern C# application    |
