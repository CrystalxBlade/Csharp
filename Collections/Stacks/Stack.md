## What is a Stack?

### A Stack<T> is a collection that follows the LIFO (Last In, First Out) principle.

### Think of a stack of plates 🍽️.

```
Top
┌────────┐
│ Plate3 │ ← Last plate added
├────────┤
│ Plate2 │
├────────┤
│ Plate1 │ ← First plate added
└────────┘
```

### You can only take the top plate.
