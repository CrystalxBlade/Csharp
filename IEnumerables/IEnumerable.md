# IEnumerable<T>

## Definition
IEnumerable<T> is an interface that represents a collection of elements that can be iterated using a foreach loop.

## Why use IEnumerable?

- Makes methods flexible.
- Supports foreach iteration.
- Used by LINQ.
- Supports deferred execution.
- Can work with List, Array, HashSet, Queue, etc.

## Common Uses

✔ foreach
✔ LINQ
✔ Method Parameters
✔ Method Return Types
✔ Deferred Execution

## Limitations

❌ Cannot Add()
❌ Cannot Remove()
❌ Cannot Insert()
❌ Read-only interface
