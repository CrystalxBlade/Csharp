## LINQ - Language Integrated Query

### It's a query language that is introduced in .Net 3.5 framework for working with 
relational database SQL Server.

### Linq to SQL is not only about querying the data but also allow us to perform Insert,
Update and Delete Operations also and we call them CRUD operations.

### linq to Objects: Arrays, Collections, etc.

### linq to databases: DataTables, Relational Database tables.

### linq to XML: XML Files
