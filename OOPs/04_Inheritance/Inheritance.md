## Types of Inheritance in C#:

- **Single Inheritance** ✅ (One class inherits another)
- **Multilevel Inheritance** ✅ (`A -> B -> C`)
- **Multiple Inheritance** ❌ (C# doesn't support it directly, but you can use **interfaces** for it)
- **Hierarchical Inheritance** ✅ (One base class, many derived classes)
